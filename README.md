# Panic Meter

Students handle many deadlines such as exams, records and projects. Panic Meter calculates a panic score so students can realise how much work is pending, which causes stress.

## Built With
- Python Flask
- SQLite
- HTML, CSS, JavaScript
- Chart.js (for the gauge)

## How to Run
1. Install Flask: `pip install flask`
2. Run the app: `python run.py`
3. Open http://127.0.0.1:5000 in your browser
